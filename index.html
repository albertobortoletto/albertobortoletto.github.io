  • Building a fully self-hosted RAG pipeline: PyMuPDF text extraction, overlapping chunking, multilingual E5 embeddings, and a Qdrant vector store running in Docker. Nothing leaves the machine.
  • Two-stage retrieval — a fast bi-encoder shortlists 20 candidates, then a cross-encoder reranker narrows to the top 5. The resulting score gap (0.84 for the correct chunk, under 0.01 for everything else) is wide enough to set an abstain threshold rather than answer from the wrong document.
  • Traced near-random ranking on Italian text to a reranker shipping English/Chinese only, and fixed retrieval quality by moving to a multilingual model. Re-indexing is idempotent via deterministic UUIDv5 point ids.
  • Status: retrieval works end to end. LLM generation, FastAPI backend and OCR for scanned PDFs are next.
